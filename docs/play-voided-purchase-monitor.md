# Google Play 취소·환불 감지

`monitorVoidedPlayPurchases`는 6시간마다 Play의 최근 30일 취소·환불 목록을 페이지 끝까지 조회합니다. 여러 수량의 부분 환불도 목록에 포함합니다. 새 내역은 토큰과 주문 번호를 저장하지 않고 `playVoidedPurchaseReviews`에 남깁니다. 이 컬렉션은 서버 전용입니다.

이는 **감지와 운영자 검토 목록**이며, 환불 자동 처리나 이용자 알림 기능은 아닙니다. 연못, 코이, 광고 제거 등 기존 혜택을 수정하지 않습니다. 클라우드 로그의 `Play voided purchases require review` 경고 및 해당 컬렉션을 운영자가 확인해야 하며, 별도의 메일·푸시 알림은 설정되어 있지 않습니다. `matchedPurchase: false`이면 장부에서 해당 구매를 찾지 못한 것이며 테스트 주문인지 알 수 없습니다.

오류는 토큰 유출을 막기 위해 상세 응답 없이 기록합니다. 스케줄러 또는 Play API 접근에 장기간 장애가 나면 30일보다 오래된 취소는 이 목록만으로 놓칠 수 있으므로 운영상 장애 감시와 별도의 복구 절차가 필요합니다. 동일 내역의 재조회는 같은 검토 항목을 재생성하지 않습니다.

구매 철회 이후 혜택의 자동 회수는 미구현입니다. 특히 유료 연못 수만 줄이면 기존 연못 데이터 및 이후 재구매 시 실제 연못이 추가되는 방식이 어긋날 수 있어, 기존 연못과 코이를 보존하고 이용자에게 설명하는 처리와 함께 설계·검증해야 합니다.
