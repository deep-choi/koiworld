# 공지사항·업데이트 운영 가이드

공지사항과 업데이트 글은 Firestore `news` 컬렉션에 저장되고, 앱의 **설정 → 소식** 화면에서 관리자가 직접 쓰고 고칩니다. 글을 올리거나 고칠 때 앱을 다시 배포할 필요는 없습니다.

## 처음 한 번: 관리자 지정

1. Firebase 콘솔 → Authentication → 사용자 목록에서 관리자 계정의 **사용자 UID**를 복사합니다. 게스트(익명) 계정은 관리자가 될 수 없습니다.
2. Firestore Database → 컬렉션 `admins`를 만들고, **문서 ID를 그 UID로** 하는 문서를 추가합니다. 필드는 아무거나 하나(예: `name: "운영자"`) 넣으면 됩니다.
3. 보안 규칙을 배포합니다: `firebase deploy --only firestore:rules`
4. 앱에서 그 계정으로 로그인하고 소식 화면을 열면 아래에 "관리자"가 보이고, 공지사항·업데이트 목록에 **글쓰기** 버튼이 나타납니다.

관리자를 빼려면 `admins`에서 그 문서를 지우면 됩니다.

## 글쓰기

- 소식 → 공지사항 또는 업데이트 → **글쓰기**
- 본문은 그대로 보입니다. **빈 줄**을 넣으면 문단이 나뉩니다.
- **공개**를 끄면 관리자에게만 보이는 임시 글이 됩니다. 미리 써 두고 나중에 공개할 때 씁니다.
- **상단 고정**을 켜면 날짜와 상관없이 목록 맨 위에 옵니다.
- **게시일**은 목록 정렬과 날짜 표시에 쓰입니다.
- 글을 열고 **수정**을 누르면 고치거나 삭제할 수 있습니다.

## 앱에 들어 있는 기본 글

`config/community.ts`의 `NEWS`는 앱에 함께 들어가는 기본 글입니다. 서버에 글이 하나도 없거나 서버에 연결할 수 없을 때만 보입니다. 서버에 글이 생기면 서버 글만 보이므로, 처음 운영을 시작할 때 목록의 **앱 기본 글 N개 서버에 올리기** 버튼으로 기본 글을 서버에 올려 두세요. 기본 글을 수정해서 저장해도 서버에 올라갑니다.

## 동작 방식

- 일반 사용자는 공개 글만 읽을 수 있고, 쓰기는 `admins`에 있는 계정만 가능합니다 (`firestore.rules`의 `news`, `admins`).
- 마지막으로 불러온 글은 기기에 저장해 두었다가, 오프라인일 때 보여 줍니다.
- 코드: `services/news.ts`(서버), `utils/newsPosts.ts`(정렬·기본 글), `components/NewsBoard.tsx`(목록·본문·글쓰기), `components/CommunityModal.tsx`(화면 이동).
