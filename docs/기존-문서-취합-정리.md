## 정리한 과거 원본

에이전트가 현재 기능으로 오해할 수 있거나 프로젝트와 무관한 과거 문서는 삭제했습니다.

- 과거 게임 소개 README
- 과거 Netlify 배포 워크플로
- Obsidian 기본 환영 문서
- 비어 있던 링크 생성 문서

과거 문서의 내용을 복구해야 하는 경우 Git 기록에서 확인할 수 있습니다. 현재 작업에서는 과거 원본을 기능·배포·게임 규칙의 기준으로 사용하지 않습니다.
