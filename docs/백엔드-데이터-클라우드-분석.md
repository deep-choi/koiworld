# 백엔드/데이터/클라우드 분석

## 현재 런타임 구성

- 인증: Supabase Auth
- 데이터 저장: Supabase Postgres + `jsonb`
- 서버 로직: Supabase RPC
- 실시간 반영: Supabase Realtime

프런트 공통 진입점:

- `services/supabase.ts`

## 현재 데이터 모델(요약)

- `profiles`: 닉네임, AP, active device, 로그인 메타
- `game_states`: `SavedGameState` 전체 스냅샷, 점수
- `marketplace_listings`: 장터 매물
- `marketplace_bids`: 입찰 로그
- `pending_koi_claims`: 구매/취소 후 수령 대기 코이
- `ap_ledger`: AP 원장
- `ad_reward_claims`: 광고 보상 중복 방지
