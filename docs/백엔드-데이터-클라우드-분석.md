# 백엔드 데이터 / 클라우드 분석

## Firebase 구성
- Hosting: `koi-garden-abcf5`
- Authentication: Google 로그인
- Firestore: 개인 저장 문서와 공개 랭킹 문서 분리

## Firestore 컬렉션
- `users/{uid}`: 본인만 읽고 쓰는 개인 게임 저장소
  - `profile.nickname`
  - `activeDeviceId`
  - `gameState`
  - `honorPoints`
  - `achievementPoints`
- `rankings/{uid}`: 공개 랭킹 조회용 최소 데이터
  - `uid`
  - `nickname`
  - `honorPoints`
  - `achievementPoints`

## 프론트엔드 서비스
- 인증: `services/auth.ts`, `contexts/AuthContext.tsx`
- Firebase 초기화: `services/firebase.ts`
- 세션: `services/session.ts`
- 저장 동기화: `services/sync.ts`
- 프로필: `services/profile.ts`
- 랭킹/Firestore 어댑터: `services/cloudData.ts`

## 보안 규칙
- `firestore.rules`에서 `users/{uid}`는 본인만 접근 가능
- `rankings/{uid}`는 누구나 읽을 수 있지만, 쓰기는 본인 문서만 가능
