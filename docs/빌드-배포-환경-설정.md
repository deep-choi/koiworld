# 빌드/배포/환경 설정

## 실행 스크립트

루트(`package.json`):

- `npm run dev`
- `npm run build`
- `npm run preview`

## 환경 변수

기타:

- `GEMINI_API_KEY` (`vite.config.ts`에서 `process.env.*`로 주입)

## 프로그레시브 웹 앱

- `index.html`에서 Service Worker 등록
- `public/sw.js`: Network First + 캐시 폴백
- `public/manifest.json`: standalone PWA 메타

## 배포 방향

- 현재 웹 앱은 Vite 산출물(`dist`) 기준으로 Firebase Hosting에 배포
- Firebase Authentication과 Firestore를 사용
- Firestore Rules는 `firestore.rules`에서 관리

## 레거시 설정

- `vercel.json`은 이전 정적 배포 호환용 파일이며 운영 배포는 Firebase Hosting 기준
