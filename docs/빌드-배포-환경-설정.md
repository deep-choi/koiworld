# 빌드/배포/환경 설정

## 실행 스크립트

루트(`package.json`):

- `npm run dev`
- `npm run build`
- `npm run preview`

## 환경 변수

클라이언트 Supabase(`services/supabase.ts`):

- `VITE_SUPABASE_URL`
- `VITE_SUPABASE_ANON_KEY`

기타:

- `GEMINI_API_KEY` (`vite.config.ts`에서 `process.env.*`로 주입)

## 프로그레시브 웹 앱

- `index.html`에서 Service Worker 등록
- `public/sw.js`: Network First + 캐시 폴백
- `public/manifest.json`: standalone PWA 메타

## 배포 방향

- 현재 웹 앱은 Vite 산출물(`dist`) 기준으로 배포
- Supabase는 인증/데이터 백엔드를 담당하고, 별도 Firebase 배포 자산은 제거됨

## 버셀 설정

- `vercel.json`에 SPA rewrite 포함
