# 소스 인벤토리

이 문서는 Supabase 전환 이후의 현재 코드 구조를 빠르게 훑기 위한 요약 인벤토리입니다.

## 핵심 디렉터리

- `components/`: 모달, 장터 UI, 연못 UI, 랭킹 UI
- `contexts/`: 인증 컨텍스트
- `hooks/`: 코이 연못 상태, 업적 상태
- `services/`: 인증, 저장 동기화, 세션, 포인트, 장터, Supabase 클라이언트
- `supabase/`: 마이그레이션 SQL
- `types/`: 온라인 호환 타입
- `utils/`: 유전, 렌더링, 오디오, 물 효과 등 도메인 로직
- `docs/`: 프로젝트 분석 및 운영 문서

## 현재 중요한 파일

- `App.tsx`
- `contexts/AuthContext.tsx`
- `services/auth.ts`
- `services/supabase.ts`
- `services/sync.ts`
- `services/marketplace.ts`
- `services/cloudData.ts`
- `hooks/useKoiPond.ts`
- `hooks/useAchievements.ts`
- `supabase/migrations/20260408_000001_initial_schema.sql`

## 제거된 레거시 범주

- 기존 클라우드 클라이언트 SDK
- 기존 서버리스 함수 소스
- 기존 프로젝트 설정 및 규칙 파일
