# 소스 인벤토리

이 문서는 현재 코드 구조를 빠르게 훑기 위한 요약 인벤토리입니다. 상세한 게임 규칙과 에이전트 작업 기준은 [에이전트용 게임·구조 가이드](./에이전트-게임-구조-가이드.md)를 우선 참고합니다.

## 핵심 디렉터리

- `components/`: 모달, 연못 UI, 랭킹 UI
- `contexts/`: 인증 컨텍스트
- `hooks/`: 코이 연못 상태, 업적 상태
- `services/`: 인증, 저장 동기화, 세션, Firebase/Firestore 클라이언트
- `types/`: 게임 및 온라인 호환 타입
- `utils/`: 유전, 렌더링, 오디오, 물 효과 등 도메인 로직
- `docs/`: 프로젝트 분석 및 운영 문서
- `android/`: Capacitor Android 래퍼 프로젝트
- `public/`: PWA 자산, 아이콘, 사료/옥수수 이미지, BGM
