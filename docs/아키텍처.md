# 아키텍처

## 상위 구조

1. 진입점: `index.tsx`
2. 앱 조립/UI 조정: `App.tsx`, `components/*`
3. 게임 상태: `hooks/useKoiPond.ts`, `hooks/useAchievements.ts`
4. 도메인 로직: `utils/genetics.ts`, `utils/achievements.ts`, `utils/GameEngine.ts`
5. 인프라: 인증, 로컬 저장, 클라우드 저장, 세션, 탭 잠금
6. 백엔드: Firebase Authentication, Firestore, Firebase Hosting

## 주요 데이터 흐름

1. `index.tsx -> ErrorBoundary -> AuthProvider -> App`
2. 앱 시작 시 `App.tsx`가 `SAVE_GAME_KEY`의 로컬 상태를 읽습니다.
3. `AuthProvider`가 Firebase 인증 상태를 복원합니다.
4. Android에서는 Play Games 로그인 후 Firebase credential 연결을 시도하고, 실패하면 익명 사용자 fallback을 사용할 수 있습니다.
5. 로그인 사용자는 `startSession()`과 `loadUserDataOnce()`를 병렬로 실행합니다.
6. `App.tsx`는 로컬 상태를 주기 저장하고, 클라우드 준비가 끝난 로그인 사용자에 대해서만 Firestore 저장을 수행합니다.
7. Firestore 게임 상태 listener가 다른 저장 결과를 수신하면 현재 React 상태에 반영합니다.

## 상태와 렌더링 경계

- React 상태는 저장 가능한 게임 모델과 UI 상태의 기준입니다.
- `GameEngine`은 캔버스에서 코이 이동·먹이 추적·충돌·시각 효과를 처리하는 런타임 엔진입니다.
- 엔진 내부의 매 프레임 위치와 물리 상태를 React `setState`로 올리지 않습니다.
- `Pond.tsx`가 엔진을 생성하고 코이·먹이·테마·수질·선택 상태를 엔진에 동기화합니다.
- `KoiRenderer`는 코이 몸체, 점, 지느러미, 그림자와 정밀 클릭 판정을 담당합니다.
- `WaterEffects`는 입자, 물결, 표면 거품과 수질 오버레이를 담당합니다.

## 저장 동기화

- 로컬 저장: `services/localSave.ts`와 `App.tsx`
- 클라우드 진입점: `services/sync.ts`
- Firestore 어댑터: `services/cloudData.ts`
- 로그인 후 자동 클라우드 저장: 현재 15초 간격, 상태 payload가 바뀐 경우만 수행
- 중복 자동 저장 방지: 저장 중인 요청이 끝나기 전에는 다음 자동 저장을 시작하지 않음
- 업적 저장: 로컬·클라우드 업적 ID를 합집합으로 병합해 과거 달성 기록이 사라지지 않도록 함

## 인증과 세션

- `contexts/AuthContext.tsx`: 앱 전체에 사용자 상태 제공
- `services/auth.ts`: Google, 이메일/비밀번호, Android Play Games, 익명 fallback
- `services/session.ts`: Firebase 사용자 문서의 `activeDeviceId` 관리
- `services/tabLock.ts`: 같은 브라우저의 중복 탭 자동 저장 방지

현재 실제 앱에서 적극적으로 사용되는 중복 실행 보호는 `tabLock.ts` 기반 브라우저 탭 잠금입니다. 원격 기기 세션 listener 관련 함수는 인프라에 존재하므로 수정 전 실제 호출 여부를 확인해야 합니다.

## Firestore 경계

- `users/{uid}`: 사용자 프로필, 세션, 전체 게임 상태
- `rankings/{uid}`: 공개 랭킹용 닉네임과 점수
- `firestore.rules`: 사용자 문서 소유권 및 랭킹 문서 쓰기 검증

## 주의 포인트

- `App.tsx`에 많은 상태와 이벤트 핸들러가 집중되어 있습니다.
- `utils/GameEngine.ts`는 React와 별도의 연속 `requestAnimationFrame` 루프를 가집니다.
- `components/Koi.tsx`와 `components/SingleKoiCanvas.tsx`에도 별도 애니메이션 루프가 있으므로 모달 렌더링과 중복되지 않는지 확인합니다.
- `services/geminiService.ts`는 현재 실질적인 게임 흐름에 연결되어 있지 않습니다.
- `index.html`은 Tailwind CDN을 사용합니다.
- 과거 원본 문서는 현재 작업 기준에서 제외했습니다. 필요한 경우 Git 기록에서 확인합니다.
