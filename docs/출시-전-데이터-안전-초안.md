# 출시 전 데이터 안전·정책 초안

이 문서는 Play Console의 Data safety, 개인정보처리방침, 계정 삭제 안내를 작성하기 위한 내부 사실 확인용 초안입니다. 공개 정책 문서가 아니며, Play Console 제출 전에 실제 Firebase·Play Console 설정과 대조해야 합니다.

## 현재 코드에서 확인되는 계정·데이터 흐름

### 인증

- 익명 Firebase 계정
- Google 계정
- Android Play Games 계정
- 이메일/비밀번호 계정
- 인증 과정에서 Firebase 사용자 UID가 생성됩니다.
- 이메일·표시 이름·프로필 사진은 제공된 로그인 방식에 따라 존재할 수 있습니다.

### Firebase Authentication에 연결되는 정보

- Firebase UID
- 로그인 제공자
- 이메일(이메일 계정 또는 제공자가 반환하는 경우)
- 표시 이름과 프로필 사진 URL(제공되는 경우)

### Firestore 개인 문서 `users/{uid}`

- 프로필 닉네임, 프로필 사진 URL
- 생성 시각, 최근 로그인 시각, 업데이트 시각
- 활성 기기 식별자
- 게임 저장 상태: 연못, 코이, 인벤토리, 재화, 업적 등 게임 진행 정보
- 명예 트로피 점수와 업적 점수

개인 문서는 인증된 동일 사용자의 UID로만 읽고 게임 저장을 할 수 있습니다. 랭킹 점수와 업적 보상 필드는 일반 클라이언트 저장에서 변경되지 않도록 보호되어 있으며, 서버 함수만 변경할 수 있습니다.

### Firestore 공개 랭킹 문서 `rankings/{uid}`

- UID
- 닉네임
- 프로필 사진 URL(있는 경우)
- 명예 트로피 점수와 업적 점수
- 업데이트 시각

랭킹 문서는 누구나 읽을 수 있습니다. 따라서 Play Console 제출 전 공개 프로필·점수 노출을 서비스 설명과 개인정보처리방침에 반영할지 확인해야 합니다.

### 기기 로컬 저장

- 게임 진행 상태
- 수동 저장 상태
- 기기 세션/중복 실행 제어용 식별자

현재 앱에는 광고 SDK, 인앱 결제, 별도 분석 SDK, 충돌 보고 SDK를 직접 연결한 코드가 확인되지 않습니다. Play Console 입력 전 실제 빌드와 Firebase 콘솔 설정에서 다시 확인해야 합니다.

## 계정 삭제 동작

앱의 계정 화면에서 삭제를 시작하면 다음 순서로 처리합니다.

1. 필요한 경우 최근 로그인 재인증
2. 서버 함수가 `users/{uid}`, `rankingState/{uid}`, `rankings/{uid}`와 랭킹 이벤트 기록 삭제
3. Firebase Authentication 계정 삭제
4. 이 기기의 게임 저장 데이터 삭제

Firebase 또는 네트워크 오류가 발생하면 완료로 표시하지 않습니다. Google Play 외부 계정 삭제 요청 URL은 공개 웹 페이지를 만든 뒤 Play Console에 등록해야 합니다.

## 제출 전에 결정할 항목

- 개발자 표시명
- 문의 이메일
- 공개 개인정보처리방침 URL
- 외부 계정 삭제 요청 URL
- 랭킹의 UID·닉네임·프로필 사진 공개 여부와 안내 문구
- 랭킹 공개 범위와 서버 함수 배포 여부
- Play Games 로그인과 익명 계정 연결을 실제 기기에서 허용할지
