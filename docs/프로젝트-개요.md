# 프로젝트 개요

## 한 줄 요약

Koiworld는 React + Vite + Firebase 기반의 코이 육성·교배·수집 게임입니다.

## 현재 핵심 기능

- 코이 육성: 먹이, 성장 단계(`fry`/`juvenile`/`adult`), 스태미나, 수질
- 유전/교배: 기본 색상, 숨은 유전자, 점 패턴, 점 표현형, 명도, 채도
- 경제: ZP 기반 사료·코이·연못·트로피 구매, 코이 판매, 연못 청소
- 업적/랭킹: 유전 조건 기반 업적, 옥수수 보상, 업적 점수·명예 트로피 랭킹
- 저장: 로컬 자동 저장, 로그인 사용자의 Firestore 클라우드 저장
- 인증: 웹 Google/이메일 인증, Android Play Games 인증 시도, 익명 fallback
- 플랫폼: 웹 PWA와 Capacitor Android 앱

현재 병듦/질병 시스템과 치료제 아이템은 제거되어 있습니다. 야간 전환은 비활성화되어 있고, 연못 테마는 현재 무료입니다.

## 기술 스택

- 프론트엔드: React 19, TypeScript, Vite 6
- 스타일: Tailwind CDN 및 프로젝트 CSS
- 렌더링: Canvas 기반 `utils/GameEngine.ts`, `utils/koiRenderer.ts`
- 인증/백엔드: Firebase Authentication, Firestore
- 배포: Firebase Hosting
- 모바일 래퍼: Capacitor Android

## 엔트리 포인트

- 웹 진입점: `index.tsx`
- 메인 앱: `App.tsx`
- 인증 컨텍스트: `contexts/AuthContext.tsx`
- 연못 상태: `hooks/useKoiPond.ts`
- 업적 상태: `hooks/useAchievements.ts`
- 게임 렌더링: `components/Pond.tsx`, `utils/GameEngine.ts`, `utils/koiRenderer.ts`
- 유전/판매가: `utils/genetics.ts`
- 클라우드 데이터: `services/cloudData.ts`, `services/sync.ts`

## 현재 운영 규칙

- 운영 초기 ZP는 `2000`, 개발 환경 초기 ZP는 `10000`입니다.
- 기본 사료 1개는 펠릿 3개를 생성합니다.
- 옥수수 펠릿은 현재 `feedAmount=3`입니다.
- 코이 판매가는 점 개수, 점 색상, 명도, 채도, 기본 유전자, 성장 단계, 스태미나를 반영하며 최종 1.5배가 적용됩니다.
- 같은 브라우저의 중복 탭이 감지되면 한 탭만 자동 저장과 게임 입력을 수행합니다.
