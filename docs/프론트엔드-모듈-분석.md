# 프론트엔드 모듈 분석

## `App.tsx` 책임

- `useKoiPond`와 인증 상태 조립
- ZP, 사료, 옥수수, 명예 점수 등 상위 게임 상태 관리
- 먹이, 교배, 판매, 청소, 상점 구매 이벤트 처리
- 저장/불러오기 및 새 게임 흐름 제어
- 인증 후 프로필·세션·Firestore 초기화
- 업적 해금·보상 수령, 랭킹 모달, 계정 모달 제어
- 15초 주기 로컬/클라우드 저장 조정

`App.tsx`는 현재 책임이 큰 편이므로 단순 UI 수정도 저장·인증·게임 상태에 영향을 줄 수 있습니다.

## 게임 상태 훅

### `hooks/useKoiPond.ts`

- 연못과 코이 배열 관리
- 활성 연못 관리
- 기본 사료/옥수수 인벤토리 관리
- 먹이 펠릿 생성 및 섭취 처리
- 성장 단계 변경, 스태미나, 수질 감소
- 교배 자손 추가, 코이 판매를 위한 제거, 연못 이동
- 장식, 테마, 이름 변경

기본 사료 1개는 펠릿 3개를 만들고, 옥수수도 펠릿 3개를 만들며 펠릿별 성장 수치는 `3`입니다.

### `hooks/useAchievements.ts`

- 사용자별 업적 로드
- localStorage와 Firestore 업적 병합
- `unlockedIds`와 `claimedIds` 관리
- 해금/보상 수령 시 로컬·클라우드 저장
- 한 번 해금/수령된 업적이 사라지지 않도록 단조 증가 방식 유지

## 주요 컴포넌트

### 연못과 코이

- `components/Pond.tsx`: 캔버스, 엔진 생성, 연못 외부 장식과 애니메이션 UI
- `components/Koi.tsx`: 별도 코이 캔버스/미리보기 컴포넌트

- `components/PondInfoModal.tsx`: 연못·코이 목록, 이동, 판매, 교배
- `components/KoiDetailModal.tsx`: 코이 상세 정보와 판매

### 조작과 경제

- `components/ControlBar.tsx`: 메뉴, 인벤토리, 먹이 모드, 연못 현황, 테마, 업적, 랭킹
- `components/ShopModal.tsx`: 사료, 옥수수, 기본 코이, 연못 확장, 명예 트로피
- `components/ThemeModal.tsx`: 현재 무료 테마 선택
- `components/CleanConfirmModal.tsx`: 수질 청소 확인

### 온라인/UI 모달

- `components/AuthModal.tsx`: 웹 인증과 게스트 진입
- `components/AccountModal.tsx`: 프로필 및 인증 소스 표시
- `components/SessionConflictModal.tsx`: 세션 충돌 UI 인프라
- `components/AchievementModal.tsx`: 업적 해금 및 보상 수령
- `components/RankingModal.tsx`: 업적 랭킹과 트로피 랭킹
- `components/SaveLoadModal.tsx`: 새 게임/저장 관련 메뉴

## 주요 사용자 흐름

1. 조작바에서 사료를 선택하면 먹이 모드가 활성화됩니다.
2. 연못을 클릭하면 먹이 1개가 3개 펠릿으로 뿌려집니다.
3. `GameEngine`이 가장 가까운 먹이를 추적하고 코이가 먹으면 React callback을 호출합니다.
4. 코이를 선택하면 교배 선택 목록에 추가됩니다.
5. 성체 2마리가 선택되고 조건을 만족하면 200 ZP로 교배합니다.
6. 코이 상세나 연못 현황에서 판매하면 `calculateKoiValue()`가 계산한 ZP를 획득합니다.
7. 업적 조건을 만족하면 업적이 해금되고, 사용자가 보상을 수령합니다.

## UI 수정 시 주의

- 판매가는 UI에서 재계산하지 말고 `calculateKoiValue()`를 사용합니다.
- 먹이 수량 차감은 인벤토리 아이템 1개 기준이며 펠릿 3개 생성과 구분합니다.
- 캔버스 엔진의 위치와 React 저장 상태의 위치를 혼동하지 않습니다.
- 모달을 추가할 때 별도 `requestAnimationFrame` 루프가 필요한지 먼저 확인합니다.
- 모바일 화면에서는 safe area, 작은 viewport, 실제 탭 동작을 확인합니다.
