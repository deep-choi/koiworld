# 프론트엔드 모듈 분석

## App.tsx 책임
- 연못/코이 상태 조립
- 먹이, 교배, 판매, 청소 이벤트 처리
- 상점, 저장/설정, 계정, 업적, 랭킹 모달 제어
- 로그인 후 세션 시작과 클라우드 저장 동기화

## 주요 컴포넌트
- 연못: `Pond.tsx`, `PondInfoModal.tsx`, `KoiDetailModal.tsx`
- 조작바: `ControlBar.tsx`
- 경제/상태: `ShopModal.tsx`, `ThemeModal.tsx`, `CleanConfirmModal.tsx`
- 온라인/계정: `AuthModal.tsx`, `AccountModal.tsx`, `SessionConflictModal.tsx`
- 업적/랭킹: `AchievementModal.tsx`, `RankingModal.tsx`

## 주요 사용자 흐름
- 먹이 선택 후 연못 클릭으로 코이 성장
- 성체 코이 2마리 선택 후 ZP를 지불해 교배
- 코이 상세 또는 연못 현황에서 코이를 판매해 ZP 획득
- 수질이 낮아졌을 때 ZP를 지불해 연못 청소
- 업적 달성 후 보상 수령 및 랭킹 반영
